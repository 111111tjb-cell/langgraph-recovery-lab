The timeline uses recorded events from two processes. Replay advances by event, rather than reproducing measured timing. A cancelled node without a result should run again. This experiment does not establish exactly-once external effects or recovery after a hard kill.

Reproduce it on your machine

Use Python 3.12+. Preparation downloads pinned dependencies; the experiment uses local SQLite with no LLM, API key or external database.

git clone https://github.com/111111tjb-cell/langgraph-recovery-lab.git
cd langgraph-recovery-lab
python -m recovery_lab prepare
python -m recovery_lab compare

Completed work should be reused. Work cancelled before producing a result should be retried. See the verified platform scope and limits.
